# 场记 changji

AI 电影制作平台。从剧本到成片的本地编排引擎，支持真人与动漫双风格。

名字取自影视工作里的「场记」，这个岗位负责的正是这套软件要做的事：
维护分镜表、盯住跨镜头的连续性、记录每一条的状态。

## 这是什么

它不是生成模型，是把一堆生成模型串成生产线的编排层。
**一个二进制**：界面、接口、编排、出图、出片、配音、大模型全在进程内，
没有第二个服务要起。大模型也可以指到远端任何兼容 OpenAI 接口的服务上。
场记负责的是分镜表、资产库、任务调度、质量闸门和成片装配。

```bash
changji --doctor        # 体检，缺什么它会说
changji --port 8080     # 起服务，浏览器打开就是界面
```

装、配、排障见 [docs/安装与运行.md](docs/安装与运行.md)。

## 设计要点

**分镜表是中枢。** 所有阶段读写同一份结构化数据，阶段之间不传自由文本。

**角色外观由程序拼，不由模型写。** 分镜表的 schema 里没有任何描述长相、
发型、服装的字段，模型只能填角色 id 和本镜可变项；外观描述由程序从资产库
机械拼接，逐字节相同。

> 注意这一条**靠的是"模型没有那个字段可填"加"拼接在程序里"**，不是靠
> 语法采样兜底：2026-09-14 起结构约束整个交给提示词，schema 以文字贴在
> 提示词后面发，没有 GBNF、也不发 `response_format`（见
> `cpp/src/llm/client.cpp`）。所以 enum / required / minLength 对模型都
> **只是建议**，真正硬的是"字段不存在"和"这段字是程序拼的"。

**配音先行。** 先跑配音拿到真实时长，再反推锁定镜头时长。音画从源头对齐。

**质量闸门 + 重试降级。** 每一镜出片后过闸门（硬切、时长偏差、响度……），
没过就换种子重试，超限留最后一版并标记降级——无人值守时停下来等于整章废掉。

> 早先还有一档"草稿档先跑一遍再升级成片档"。挂上 Turbo LoRA 之后两档拉不
> 开差距，`skip_draft` 现在**默认为真**，正常流程直接出成片档。想要那一档
> 得显式传 `skip_draft: false`。

**成片是一部完整的电影，一个文件。** 一章按自己的内容写完拍完，最后所有出了
片的章按章序接成一部电影——章的长短是内容的结果，不是反过来让内容去凑长度。
没片的那几章跳过，不拦着别的章，跳了哪几章在页面上说清。
