# 电影质感方案

调研时间 2026-09-14。硬件：AutoDL 单卡 RTX 5090 32GB。出片模型 MiniMax-H3（Q4_K_M + Turbo LoRA 6 步，704×1280，24fps），首帧 Qwen-Image 基础版，配音 Qwen3-TTS，装配 ffmpeg。

## 落地状态（2026-09-15）

四段全部落进代码（分支 claude/cinematic-video-production-plan-ed74c5），本机 972 个单测过、每条 ffmpeg 命令在真 ffmpeg 上跑过一遍。用户定的一条改动：**H3 的原生音轨有没有台词都留**，有台词时压在台词底下再侧链压一道。

| 段 | 开关在哪 | 落在哪 |
|---|---|---|
| 后期链：柔化 → 调色（内置曲线或 LUT）→ 颗粒 →（横屏）遮幅 | 项目 `[look]`（项目页「这部片子」弹窗：胶片 / 干净 / 关） | `media::look_filters`，挂在装配 normalize 的 `-vf` 上 |
| 声音：环境声（各镜原生音轨）/ 配乐 / 侧链压 | 项目 `[sound]`；配乐命令在全局 `[sound].music_command` | `media::mix_args` 的 MixOptions；`stages/music` + `tools/music_ace_step.py` |
| 分镜表：机位、焦段、光进 required；运动描述按时间码分段；视频负向词；`global_style` 配方 | `prompts.toml` `[storyboard]` `[compose.lens]` `[style]` `[bible]` | `Shot::lens/lighting/continuous_with_prev`，`PromptComposer` 镜头层和 `motion_prompt` |
| 出片：关键镜多条 take 挑、尾帧串镜、尾帧 FL2VA | 项目 `[video].hero_takes / chain_frames`；分镜的 `continuous_with_prev` / `last_frame_prompt` | `stages::RenderExtras`、`pick_take`、frames 阶段的 `<id>_end.png`、`VideoRequest::end_image` |
| 放大 | 全局 `[upscale].command`（空 = 不放大） | 装配时每镜先过命令再调色 |
| 分档 | `[models].video_lora_tiers = "draft"` + 单集页按镜头重跑成片档 | 机制原来就有，模板里写了怎么开 |

**还没验的**：服务器上出一镜看原生音轨的内容和音量；三个新必填字段在真实项目上的凑数率；ACE-Step / SeedVR2 要在服务器装 Python 环境，包装脚本没在真机跑过；`music_ace_step.py` 按上游 2026-09 的 API 写的。

## 按场分镜（2026-09-15）

长视频最要紧的是连贯，连贯的单位是场。改法是让「场」成为剧本里的结构，分镜按场来：

- **剧本**多一种拍子 `kind=scene`，写「日/夜 · 内/外 · 地点」三样，渲染成场次头「【第1场 · 夜 · 内 · 天台】」。写剧本的两条提示词（正片、从故事写）都要求换地方或换时间就起一场，第一拍就是第一场。剧本页把它画成一条分场线。
- **分镜**先按场次头切场（`stages::split_scenes`）。两场以上一场一次拆（`pipeline::run_storyboard`）：这一场的时段和地点钉在提示词里，地点按名字接到资产库的场景，接上了就把 `location_id` 钉进 schema 的枚举并进 required，拆出来的镜头由引擎统一盖上 `scene_id = sN` 和 `location_id`，第一镜不接上一场的帧；下一场的提示词带上上一场最后一镜的画面。时长按各场的拍数分。只有一场（老剧本没有场次头）走整集那条路，一个字不变。
- 三处调用（POST /api/plan、单集页重出、批量补分镜）共用 `run_storyboard`。

没做的：场内的房间音底子还是逐镜各出一条；连贯性报表（跨镜人脸相似度、场内首帧和空景图相似度、切点音轨跳变）还没有。

## 一句话结论

「电影质感」不是一个词，是三层各自几件具体的事：

| 层 | 具体是什么 | 我们现在 |
|---|---|---|
| 拍前（分镜表） | 每一镜写全：景别、机位、运镜、**焦段和景深**、**光（时段/光源/方向/软硬）** | 景别有、运镜刚修好、机位不在 required 里所以全是平视、焦段景深和镜头级光线没有 |
| 拍中（出片） | 分辨率、步数、跨镜一致性、真实的运动和物理 | Turbo 6 步全集通吃、首帧不能收参考图、尾帧没接 |
| 拍后（装配） | 时序放大 → 调色（胶片 LUT）→ 颗粒和柔化 → **四层声音** → 剪辑节奏 | **零**。`-f concat -c copy`，一帧没碰过；声音只有台词一层 |

行业里反复出现的一句话：**成片的「完成度」大半来自声音和调色，不是来自模型**。这两样恰好是我们一点没做的，也是最便宜的。所以顺序是：先后期和声音（一两天能看出差别），再提示词和分镜表，最后动模型和分辨率。

## 行业怎么定义（查到的），对着我们逐条看

| 要素 | 行业做法 | 我们 |
|---|---|---|
| 时间基础 | 24fps + 180° 快门（1/48 秒运动模糊）是「电影」的物理底子 | H3 硬钉 24fps ✓。AI 视频没有真运动模糊，只能靠后期颗粒 + 柔化补回「胶片感」 |
| 镜头语言 | 提示词像导演写 shot card：主体 + 动作 + 环境 + 运镜 + 机位 + 焦段 + 光 + 片种；30–60 词；「35mm anamorphic」「85mm 人像压缩背景」这种字面焦段有效 | 景别 ✓ 运镜 ✓ 机位 ✗（不在 required，51/51 镜全 eye_level）焦段/景深 ✗ |
| 光 | 「真实感最强的锚」。要说清时段、光源、方向、软硬、动机光（画面里的灯是光源）。有制作组把 85:15 的暗亮比写进每一帧提示词 | 场景层有一句 `lighting`（光线基调）；镜头级没有字段；`global_style` 默认「柔和自然光，浅景深」全剧一句 |
| 色 | 胶片打印 LUT（Kodak 2383 / Fuji 3510）按 50–70% 强度套，AI 画面本身饱和度和对比已经偏高，全强度会压死暗部；先逐镜校曝光白平衡，再全局 LUT | 无 |
| 胶片伪影 | 35mm 颗粒 8–15% 不透明度，打破 AI 那种「过干净过锐的表面」；先做 <1 px 高斯柔化压掉微锐化；halation / bloom 是第二档 | 无 |
| 画幅 | 横屏 2.39:1 遮幅；竖屏短剧不变 9:16，靠景别偏近（fal 对 ReelShort / DramaBox 的建议：多用近景、特写、大特写） | 9:16 / 16:9 按 orientation |
| 分辨率 | **本地 H3 只到 768p**（2K 是 API 独占的 Regenerate-2K 阶段，没开源）。行业做法：原生分辨率出片，时序放大 2×（RTX VSR / SeedVR2），200% 放大对比看不出差别 | 704×1280 直出；RealESRGAN 逐帧（慢 10 倍、逐帧无时序一致性会闪） |
| 声音 | 四层：台词 / 环境和房间音 / 动效 / 配乐。「音频对成片完成度的贡献不成比例地大」 | 台词一层 + loudnorm。**H3 每镜原生立体声被 `-an` 丢掉** |
| 剪辑 | 镜头长短交替；J/L cut；180° 和视线匹配；连续动作把上一镜尾帧当下一镜首帧 | 硬切 ✓（本来就对，溶解才是廉价感）；尾帧 FL2VA 权重装着、代码没接 |
| 一致性 | 角色定妆三视图 2–4 张当参考，每镜首帧用参考图出；行业主流都不再靠 LoRA | 基础版 Qwen-Image 不能收参考图（收了会复刻参考图，已掐），一致性只剩身份层文字 |
| 产量 | 10–15% 的镜头会漂，关键镜头多出 20–30% 挑 | 只在闸门失败时重试 |
| 步数 | Turbo LoRA 6–8 步是草稿甜点，>8 步开始过锐；定稿 20 是基线、30 是手和纹理的甜点、50 只做同种子 A/B | 全部 Turbo 6 步。分档机制在（`tiers` + `video_lora_tiers`），默认 both |

## 本地 H3 的三条硬边界（决定方案能走哪条路）

1. **2K 不开源。** 本地是 768p 阶段（1344×768 或等价像素）。要 1080p 以上只能放大。
2. **Ref2VA + 参考音频会把身份冲掉。** HF 讨论 #91 用 InsightFace 量过：FL2VA 单独 0.886，Ref2VA + 音频 0.09，换尺寸、去 LoRA、加步数、换原生 Ref2VA 权重都救不回来。参考音频本身也只管**音色**不管内容（#64）。所以**身份必须锁在首帧、走 I2VA/FL2VA**，这正是我们现在的架构，别为了口型改去 Ref2VA。
3. **一镜 5 秒是单位、12 秒会炸内核**（2026-09-13 实测）。长镜头不是电影感的来源，别往那儿使劲。

## 方案：四段，按便宜到贵

### 第一段：后期链（纯 ffmpeg，改装配那一步，一两天）

**关键发现：装配的 normalize 步骤本来就在逐镜重编码**（`assemble.cpp` 的 `normalize_args`：scale + pad + fps，再 libx264）。在那条 `-vf` 里加滤镜，**额外成本是零**，不用碰 `concat -c copy` 那一段。

每镜的滤镜链（顺序有讲究：先缩放补边，再柔化，再调色，颗粒最后）：

```
scale=W:H:force_original_aspect_ratio=decrease,pad=W:H:(ow-iw)/2:(oh-ih)/2,setsar=1,fps=24,
gblur=sigma=0.4,
split[o][g];
[g]lut3d=file=luts/kodak2383_rec709_d65.cube:interp=tetrahedral[g2];
[g2][o]blend=all_mode=normal:all_opacity=0.6,
noise=c0s=10:c0f=t+u
```

- `gblur 0.4`：不到一个像素，只压 AI 的微锐化，看不出「糊」。
- `lut3d` + `blend 0.6`：LUT 全强度套 AI 画面会压死暗部，60% 是行业给的区间中点。LUT 用 **Rec.709 输入**的版本（模型直出就是 709 SDR），别拿 DaVinci Wide Gamut / log 版的，那是给摄影机素材的。免费的在 imnz730/LUTs 仓库（`Film Looks/Rec709 Kodak 2383 D65.cube`）。
- `noise c0s=10 f=t+u`：只在亮度通道加，时间上随机（t）、均匀分布（u）。10 大概对应 8–15% 那档，肉眼调。
- 编码加 `-tune grain`，crf 18 上下。颗粒是最难编码的东西，不加这个会被 x264 当噪声抹掉，白做。
- 横屏项目再加一步 `crop=iw:iw/2.39,pad=iw:iw*9/16:0:(oh-ih)/2`（2.39:1 遮幅，容器还是 16:9）。竖屏不做。
- 第二版再考虑：halation（分出高光 → `gblur sigma=10` → screen 叠 15%）和轻 vignette。先别堆。

验收：同一集、同种子，后期链开和关各装配一版并排看。清晰度指标（拉普拉斯方差）会因柔化降 10–20%，这是预期；闸门在每镜出片后量、在装配前，不受影响。

配置上做成项目级 `[look]`：`lut` 文件、`lut_strength`、`grain`、`soften`、`letterbox`，项目页给一组预设（「胶片」「干净」「关」），默认「胶片」。

### 第二段：声音（一两天，和第一段一起做）

现在成片里台词之间是**绝对的静音**，这是最一眼「AI」的地方，比画面还明显。

1. **H3 的原生音轨别丢。** 规则很简单：**有台词的镜头照旧丢**（H3 会自己配一条和 TTS 不一样的人声，分不开）；**没台词的镜头**（空镜、动作、反应）留下，当环境声和动效。改动在 `sd_video.cpp` 那个 `-an` 按镜头有无台词决定，装配的 `amix` 多接几路输入、压在台词下 −12 dB，loudnorm 照旧。
   - 配套在提示词上：H3 是**从画面描述推声音**的（官方 I2V 系统提示词原话：用「雨打铁皮、远处车流」这种画面描述暗示声音，**别单独写音频提示词**）。分镜的 `sfx` 字段现在没人用，把它拼进无台词镜头的运动提示词里就行。
   - 已知坑：社区报过「安静段落出现咕哝声」。先靠人听，量不出来。
2. **房间音。** 有台词的镜头丢了原生音轨后还是空的。最便宜的做法：**同一场景（`location_id` 相同）的空镜原生音轨当底子**，循环、−24 dB 铺在这一场所有镜头下面。同一场戏的房间音本来就该是同一条。
3. **配乐。** ACE-Step 1.5：Apache 2.0、权重 <4 GB 显存、5090 上一条几秒钟出。一集一条 60–90 秒器乐 cue，提示词从剧本的四拍来（情绪 + 速度 + 配器）。混音压在台词下 −20 dB，台词处侧链压缩（`sidechaincompress`）。显存和 H3 错开：在配音阶段跑（那时 H3 没装着），调度器已经会管驻留。
4. 别做：MMAudio / HunyuanVideo-Foley 那类视频转音频模型。H3 自己已经出原生动效，再上一个 7–14 GB 的模型是重复的。

### 第三段：提示词和分镜表（两三天）

前提：约束只在本地后端有效（GBNF 认 minLength / required）；远端后端 schema 会被削，这几条要单独验（见 [[project-llm-backend-default]]）。

1. **`camera_angle` 进 required。** 2026-09-13 那轮是故意留的对照组，现在有了数（motion_prompt / camera_move 进 required 后凑数率 0），可以动。
2. **加两个镜头级字段。** 「不在 required 里的字段模型整个略过」是坐实过的机制，所以要做成字段，不能只在提示词里要求：
   - `lens`：枚举 `wide_24 / normal_35 / portrait_85 / tele_135`，`[compose.lens]` 词表写成「24mm 广角，透视拉伸，前景夸张」「85mm 人像，背景压缩，浅景深」这种配方，拼进首帧提示词的镜头层。
   - `lighting`：自由文本 ≤60 字，必填 minLength 12，提示词要求四样：时段、光源、方向、软硬。例如「夜，路灯从画左上斜射，硬光，半张脸在阴影里」。拼进首帧提示词，在场景层之后、镜头层之前（镜头级光要盖过场景那句基调）。
3. **`motion_prompt` 改成 H3 的时间码格式。** 官方系统提示词就是这个：`[0-2秒] …  [2-5秒] …`，每段 1–3 句，5 秒 2–3 段，**运镜要写名字 + 幅度 + 速度**（「缓慢推近半步」而不是「推近」，H3 指南明说别拿 cinematic 一个词当整个运镜指令）。`PromptComposer::motion_prompt` 现在是「运镜词 + 运动描述 + 各角色动作」用「，」串——改成把运镜词并进第一段，角色动作并进对应段。这也顺手解决了 [[project-i2v-gap-analysis]] 记的「句号后面接逗号」那条。
4. **负向词拆成图和视频两份。** 现在 `negative_base` 是图像那套（「多余的手指，画得不好的手部」），拼给视频模型没意义。H3 对**否定指令异常有效**（fal 指南原话），视频负向写：「不要溶解转场、不要形变和融化、不要片中硬切、不要黑帧、不要字幕和水印」。图像负向留给首帧。
5. **`global_style` 写成配方，不写「电影感」。** 这三个字已经烂大街（知乎 2026 那篇的标题就是这个），H3 指南也把「cinematic」列为没有信息量的词。和这仓库自己的规矩一致（prompts.toml 开头：正例换成配方）。写实线的默认改成四个槽：胶片（「35mm 胶片质感，细颗粒，高光柔和滚落」）、焦段倾向（「中长焦为主，浅景深」）、色板（「低饱和，冷暖对比，肤色保真」）、光的性格（「动机光源，暗部占七成」）。`[bible]` 的提示词让模型按这四个槽给每个项目写自己的 `global_style`。⚠️ `default_realistic` 和 Python 逐字节对拍，改了要把 `tests/golden` 语料一起改，这是允许的（文件开头写着「改了就把语料一起改」）。
6. 竖屏项目的景别倾向：`[storyboard]` 里加一句「竖屏以近景、特写、大特写为主，远景只用于交代环境」。

### 第四段：出片本身（一周）

1. **分档真正用起来。** `video_lora_tiers = draft`：草稿档 Turbo 6 步（今天的样子）看叙事和构图；成片档**不挂 LoRA、20–30 步**（30 是手和纹理的甜点，50 只做同种子 A/B）。代价：采样 157 秒 × 5 ≈ 13 分钟一镜（外推，没实测），7 镜一集 ≈ 1.7 小时。所以成片档只对**人挑过留下的镜头**跑，不是全集。⚠️ 要核一下：`runtime.cpp` 里 `final_steps` 现在明确接到的是首帧那条路（171–180 行），视频那条是否吃 tiers 的步数没确认。
2. **关键镜头多种子。** 开场钩子和集尾留扣两镜各出 2–3 个种子，先按 clipstat（运动量在区间内、清晰、无硬切）筛，再人挑。分镜表加个 `takes` 概念，`attempts` 只记失败次数不够。
3. **尾帧串镜。** 连续动作的两镜，上一镜最后一帧抽出来当下一镜首帧（`ffmpeg -sseof`），同时传 `--end-img` 走 FL2VA。我们装的就是 FL2VA 权重，`last_frame_prompt` 字段在、代码没有。两个用处：动作连贯（行业标准做法）、和「落到某个构图上」的可控性。
4. **首帧收参考图。** 换 Qwen-Image-Edit-2511（`docs/选型结论.md` 已经选过它：1–3 张参考、模型卡明说修角色漂移；2509 起要 mmproj）。这是**跨镜「这是同一个人」的唯一杠杆**，文字身份层做不到。代价：第二个图像模型 ~13 GB GGUF，和基础版轮换，调度器要管两个图像槽。ECU 不带身份层的规则保留。
5. **放大。** 出片保持 704×1280（或 H3 原生 768×1344），成片 2× 时序放大到 1080×1920。两个候选：RTX VSR（NVIDIA，15 秒片 11 秒，皮肤细节略好）和 SeedVR2 3B fp8（专治 AI 素材和退化素材，batch 必须 4n+1，24 GB 以上跑 7B）。两个都是 Python/ComfyUI 生态，**不在 sd.cpp 里**——在我们这套 C++ 管线里只能做成 sidecar（服务器起一个小 Python worker，接口就是「放大这个 mp4」，走已有的 worker_server 那条路）。RealESRGAN 逐帧那条路别再投入。⚠️ 别把底子做太低：960×540 放 2× 看不出差别，480×270 放 4× 出来的是「合成的纹理」（文件反而大 2.2 倍）。
6. **别做的**：
   - 帧插值到 48/60 fps。那是肥皂剧效果，反电影；RIFE 只用于慢动作。
   - Turbo 加到 8 步以上。作者实测 >8 只有过锐没有细节。
   - 调高 cfg。第十一轮 A/B 已证对 H3 + Turbo 不是杠杆。
   - 为口型转 Ref2VA。见上面「三条硬边界」第 2 条。

### 第五段（以后）：口型

本地现在没有干净的路：Ref2VA 收音频身份崩；参考音频只管音色；LatentSync 1.6 要 18 GB（选型结论里查过）。电影的老办法反而合适：**台词镜头多用过肩、侧脸、反应镜头和画外音，正脸说话留给短句**。分镜表已有 `needs_lipsync` 和 `face_pose`，让分镜把「正脸长台词」拆成「正脸起句 + 切反应镜头」，就是把行业的 J/L cut 用起来。做完前四段再看这条值不值。

## 做完一集是什么样（目标规格）

| 项 | 规格 |
|---|---|
| 帧率 / 出片 / 成片 | 24fps；704×1280 或 768×1344 出片；2× 时序放大到 1080×1920（横屏 1920×1080 + 2.39 遮幅） |
| 档位 | 草稿 Turbo 6 步全集；成片 20–30 步无 LoRA，只对留下的镜头；关键镜 2–3 种子 |
| 每镜提示词 | 景别 + 机位 + 焦段景深 + 光（时段/光源/方向/软硬）+ 时间码运动段（运镜名 + 幅度 + 速度）+ 视频负向 |
| 后期 | 0.4 px 柔化 → Kodak 2383 60% → 35mm 颗粒 10%，`-tune grain` |
| 声音 | 台词（TTS，−16 LUFS）/ 环境动效（H3 原生，无台词镜）/ 房间音（同场景空镜底子 −24 dB）/ 配乐（ACE-Step，台词下 −20 dB 侧链压） |
| 剪辑 | 连续动作尾帧串镜；硬切；镜长长短交替 |

## 时间和显存预算（5090，单镜 4 秒 704×1280，已实测的标出）

| 步骤 | 耗时 | 显存 | 备注 |
|---|---|---|---|
| 首帧（基础版） | 31 秒（实测） | 16 GB | 换 Edit 版估 60 秒 |
| 草稿 Turbo 6 步 | 228 秒（实测：采样 157 + 解码 58） | 峰值 28.8 GB | |
| 成片 30 步无 LoRA | ≈ 14 分钟（外推） | 同上 | 只跑留下的镜头 |
| 时序放大 2× | RTX VSR 参考 11 秒 / 15 秒片；SeedVR2 慢一个量级 | SeedVR2 3B fp8 ~12–16 GB | sidecar，和 H3 错开 |
| 调色颗粒 | ≈ 0 | 0 | normalize 已在重编码 |
| 配乐 ACE-Step | <30 秒一条 | <4 GB | 配音阶段跑 |

草稿一集（7 镜）≈ 30 分钟，和今天一样；成片档一集 ≈ 1.7 小时 + 放大。

## 验收怎么做

- **看**：同一集同种子，后期链开/关各一版并排；三个人盲选。
- **量**：clipstat 的 sharp 降 10–20% 是预期（柔化），motion 不变；跨镜身份用 InsightFace 余弦相似度（HF #91 就是这么量的），目标 ≥ 0.8。
- **听**：loudnorm 后台词 −16 LUFS；台词之间不再是数字静音。

## 顺序

1. 第一周：第一段 + 第二段（后期链、原生音轨、房间音、配乐）。一天能看出差别，先把「完成度」拿到。
2. 第二周：第三段（camera_angle、lens、lighting、时间码运动段、视频负向、配方式 global_style）+ 分档接通。
3. 第三周：Edit 模型首帧 + 尾帧串镜 + 放大 sidecar。
